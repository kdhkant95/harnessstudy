# 하네스 목적

이 문서는 Codex 하네스의 목적, 매번 달라지는 입력값, 사용자, 완료 기준을 정의한다.

## R2 목적 요약

| 항목 | 확정 내용 | 출처 |
| --- | --- | --- |
| 매번 달라지는 입력값 | `input/PRD.md` | 사용자 답변 개선 |
| PRD 기반 생성 산출물 | `output/story-service.md` | PRD 교체 구조 개선 |
| 고정 참조 문서 | `context/story-work.md`, `context/domain.md`, `context/design.md` | 기존 R0~R1 문서 기준 |
| 사용자 | 기획 겸 디자이너인 사용자 | 사용자 답변 |
| 완료 기준 | `AGENTS.md` 초안 1개가 생성되고, R0~R8 게이트가 모두 통과하면 완료한다. | 사용자 답변 + 기본값 적용 |
| 최종 오케스트레이터 파일 | `AGENTS.md` | 사용자 답변 |

## 완료 판정

하네스는 아래 조건을 모두 만족하면 완료로 본다.

| 조건 | 판정 방식 |
| --- | --- |
| `AGENTS.md` 초안 1개 존재 | 파일 존재 여부로 판정 |
| R0~R8 게이트 전체 통과 | 게이트 결과가 모두 `pass`인지 판정 |
