# 디자인 기본값과 게이트

사용자가 별도 값을 정하지 않아도 디자이너가 Figma 작업을 시작할 수 있도록 적용하는 기본값과, 단계별로 걸리는 게이트 조건을 한곳에 정리한다. 이 문서는 `context/story-work.md`의 디자인 워크플로우에만 적용하며, 서비스 기능 유저스토리인 `output/story-service.md`와 섞지 않는다.

## 기준 소스

| 기준 | 값 | 출처 |
| --- | --- | --- |
| 디자인 시스템 | MUI 디자인 시스템 | 사용자 제공 |
| 1차 시안 | 대시보드 1차 시안 이미지 | 사용자 제공 |
| 컬러 팔레트 | `assets/palette/light.tokens.json`, `assets/palette/dark.tokens.json` | 사용자 제공 zip을 작업 폴더에 복사 |
| Figma 키 스크린 크기 | 1440x1080 | 사용자 제공 |
| Figma 키 스크린 수 | 2~3개 | 사용자 제공 |

## 기본 진행값

| 항목 | 기본값 | 출처 |
| --- | --- | --- |
| 기본 테마 | Light theme 우선 | 임의 보완값 |
| 보조 테마 | Dark theme은 토큰 확인용으로 유지 | 임의 보완값 |
| 기본 화면 폭 | 1440 | 사용자 제공 |
| 기본 화면 높이 | 1080 | 사용자 제공 |
| 기본 컴포넌트 원칙 | MUI 컴포넌트를 먼저 사용하고, 커스텀 컴포넌트는 MUI로 표현하기 어려운 경우에만 사용 | 사용자 제공 기준을 운영 규칙으로 구체화 |
| 기본 시안 방향 | 대시보드 1차 시안의 상단 GNB, 카드형 위젯, 표, 숫자 요약, 상태 배지 흐름을 참고 | 사용자 제공 시안 기반 |
| 기본 산출물 | 레퍼런스 분석, 서비스 화면 설계 문서, Figma UI 키 스크린 2~3개, 내부 협의 결과 | 사용자 제공 |

## 컬러 토큰 기본값

팔레트는 첨부 zip의 토큰을 기준으로 한다. 임의 hex 값을 새로 만들지 않는다.

| 역할 | Light token | Light value | Dark token | Dark value |
| --- | --- | --- | --- | --- |
| Primary | `primary.main` | `#1976D2` | `primary.main` | `#90CAF9` |
| Secondary | `secondary.main` | `#9C27B0` | `secondary.main` | `#CE93D8` |
| Error | `error.main` | `#D32F2F` | `error.main` | `#F44336` |
| Warning | `warning.main` | `#EF6C00` | `warning.main` | `#FFA726` |
| Info | `info.main` | `#0288D1` | `info.main` | `#29B6F6` |
| Success | `success.main` | `#2E7D32` | `success.main` | `#66BB6A` |
| Background | `background.default` | `#FFFFFF` | `background.default` | `#121212` |
| Subtle background | `background.subtle` | `#FAFBFF` | 없음 | 없음 |

## 화면 기본값

| 항목 | 기본값 | 출처 |
| --- | --- | --- |
| 화면 유형 | 대시보드 키 스크린 | 사용자 제공 시안 기반 |
| 내비게이션 | 상단 GNB | 사용자 제공 시안 기반 |
| 콘텐츠 구조 | 카드형 위젯 + 숫자 요약 + 표 + 상태 배지 | 사용자 제공 시안 기반 |
| 데이터 표현 | 숫자만 단독 노출하지 않고 라벨과 상태명을 함께 표시 | PRD 및 사용자 제공 시안 기반 |
| 상태 표현 | 색상만 쓰지 않고 텍스트 상태명을 함께 표시 | PRD 기반 |
| 내부 스크롤 | 위젯 내부 스크롤은 피하고, 필요한 경우 전체보기로 연결 | PRD 기반 |
| 기본 카드 톤 | 흰 배경, 얕은 구분선, 낮은 그림자 또는 MUI Paper 계열 | 사용자 제공 시안 기반 |

## 임의 보완값 목록

아래 값은 사용자가 직접 지정하지 않았지만, 값을 정하지 않아도 작업이 진행되도록 보완한 기준이다.

| 항목 | 보완값 | 이유 |
| --- | --- | --- |
| 기본 테마 | Light theme 우선 | 첨부 시안이 밝은 테마이고, light token에 `background.subtle`이 있음 |
| Dark theme 처리 | 키 스크린 제작 필수값은 아니며 토큰 검증용으로 유지 | 사용자 요청의 주요 산출물이 1440x1080 키 스크린이기 때문 |
| 커스텀 컴포넌트 제한 | MUI로 표현이 어려운 경우에만 허용 | MUI 디자인 시스템 기준을 지키기 위함 |
| 게이트 번호 | G1~G6로 번호를 붙임 | 확인·협의 시 참조하기 쉽게 하기 위함 |
| G4 상세 위반 예시 | MUI, 팔레트, 상태명, 권한 상태 기준 위반 예시를 명시 | 실제 디자인 리뷰에서 걸리는 조건을 명확히 하기 위함 |
| 보류 처리 방식 | 위반 시 다음 단계 보류 또는 해당 화면 수정으로 정의 | 게이트가 실질적으로 작동하게 하기 위함 |
